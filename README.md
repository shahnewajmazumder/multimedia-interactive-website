# 🌐 Multimedia Interactive Website

A modern and responsive **Multimedia Interactive Website** developed to demonstrate the use of multimedia elements and interactive web features.

The website provides an engaging digital experience through **images, audio, video, CSS animations, interactive graphics, dark mode, smooth scrolling, and an interactive counter**.

## 📌 Project Overview

The **Multimedia Interactive Website** is a simple front-end web project designed to showcase how different multimedia and interactive elements can be integrated into a website.

The project focuses on creating a clean, responsive, and user-friendly interface while demonstrating fundamental web development concepts.

---

## ✨ Features

* 🖼️ **Image Gallery**

  * Multiple images displayed in a responsive gallery
  * Hover effects and image animations

* 🎵 **Audio Player**

  * Built-in HTML audio player
  * Play and control audio directly from the website

* 🎥 **Video Player**

  * Embedded HTML video player
  * Video poster and playback controls

* ✨ **CSS Animations**

  * Floating animations
  * Smooth hover effects
  * Animated visual elements

* 📊 **Interactive Graphics**

  * Animated technology skill bars
  * Dynamic graphical representation

* 🖱️ **Interactive Counter**

  * Increase counter
  * Decrease counter
  * Reset counter

* 🌙 **Dark Mode**

  * Switch between light and dark themes

* 🔄 **Smooth Navigation**

  * Navigation links to different sections
  * "Explore Now" button smoothly moves to the next section
  * Back-to-top functionality

* 📱 **Responsive Design**

  * Works on desktop, tablet, and mobile devices

## 📂 Project Structure

```text
multimedia-interactive-website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### File Description

**`index.html`**
Contains the structure and content of the website, including images, audio, video, navigation, and interactive sections.

**`style.css`**
Contains the complete styling, responsive layout, animations, hover effects, dark mode styling, and visual design.

**`script.js`**
Handles interactive functionality such as smooth scrolling, dark mode, animated skill bars, counter operations, and back-to-top navigation.

## 🎯 Project Objectives

The main objectives of this project are:

1. To understand the basic structure of an HTML5 website.
2. To implement multimedia elements such as images, audio, and video.
3. To create animations using CSS.
4. To use JavaScript for interactive website functionality.
5. To create responsive layouts for different screen sizes.
6. To implement dark mode using JavaScript and CSS.
7. To demonstrate interactive graphical elements.
8. To improve user experience through smooth navigation and animations.

## 🎨 Website Sections

### 🏠 Home

The home section introduces the website and provides an **Explore Now** button that smoothly navigates users to the next section.

### 🖼️ Image Gallery

Displays multiple images with hover animations and responsive card layouts.

### 🎵 Audio & 🎥 Video

Demonstrates HTML5 multimedia capabilities using native audio and video controls.

### 📊 Interactive Graphics

Displays animated skill bars representing HTML, CSS, and JavaScript proficiency.

### 🖱️ Interactive Counter

Allows users to increase, decrease, and reset a numerical counter using JavaScript.

### 🌙 Dark Mode

Users can switch between light and dark themes using the theme button in the navigation bar.

## 📱 Responsive Design

It supports:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries are used to adjust the layout and navigation for smaller screens.
